# ToMind – Full Stack Notes Application

A secure, full-stack notes application that allows users to create, edit, and manage personal notes with authentication and rate-limited APIs.

## Tech Stack
**Frontend:** React, TypeScript, Tailwind CSS, DaisyUI, Framer Motion  
**Backend:** Node.js, Express.js, MongoDB, JWT  
**Other:** Axios, Upstash Redis (Rate Limiting)

## Features
- User authentication with JWT (Login / Register)
- Protected routes and session persistence
- Create, edit, delete notes with user-based access control
- API rate limiting using Redis (Upstash)
- Dark / Light theme toggle with persistent state
- Responsive UI with smooth animations
